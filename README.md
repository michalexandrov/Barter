# Бартер-дашборд — как показать заказчику

Интерактивный калькулятор сделки: поставка минеральной ваты ⇄ квартиры застройщика.
Расчёты в тенге, налоговая модель Казахстана (НДС 16 %, КПН 20 %).

---

## Быстрый старт

```powershell
cd d:\Barter
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

> Просто открыть `index.html` двойным щелчком тоже можно — но тогда часть браузеров
> блокирует локальные скрипты, и QR-код для телефона работать не будет.

> **Нужно, чтобы заказчик работал с дашбордом сам, без вас, по обычной ссылке?**
> Смотрите **способ 3** — проект выкладывается в ваш GitHub, заказчику остаётся
> открыть ссылку. Ни ему, ни вам больше ничего регистрировать не нужно.

## 5 способов показать дашборд

### 1. На своём экране (ноутбук / планшет)

Откройте <http://localhost:8000> и работайте: меняйте поля, переключайте пресеты
«Осторожный / Базовый / Оптимистичный», показывайте графики.

### 2. На телефоне заказчика — по QR-коду (самый быстрый)

1. Телефон и компьютер должны быть **в одной Wi-Fi сети**.
2. Узнайте IP компьютера:
   ```powershell
   ipconfig
   ```
   Нужна строка **IPv4-адрес** активного адаптера (например `192.168.31.179`).
3. На компьютере откройте дашборд **по этому адресу**, а не по `localhost`:
   `http://192.168.31.179:8000`
4. Нажмите в шапке кнопку **QR-код** (первая иконка) — появится код.
   Заказчик наводит камеру телефона → дашборд открывается у него.

> Если QR-код не появляется — вы открыли дашборд по `localhost`.
> Адрес `localhost` существует только на вашем компьютере, телефон его не поймёт.

**Если страница не открывается с телефона** — блокирует брандмауэр Windows:
разрешите `python.exe` доступ в **частных сетях** (Параметры → Сеть и Интернет →
Брандмауэр → Разрешить работу с приложением).

### 3. Постоянная ссылка на своём GitHub (заказчику регистрация не нужна)

Это лучший вариант для сценария «заказчик работает сам»: он просто открывает ссылку
в браузере — нигде не регистрируется, ваш компьютер и Wi-Fi не нужны.

**Репозиторий уже создан и код загружен:**
<https://github.com/michalexandrov/Barter>

В публикацию не попали `CLAUDE.md`, `dist/` и `dist.zip` — они перечислены в `.gitignore`.

Осталось два действия в браузере (нужно войти в свой аккаунт GitHub).

#### Шаг 1. Сделать репозиторий публичным

Бесплатный GitHub Pages работает только с публичными репозиториями, а VS Code
опубликовал проект как приватный.

1. Откройте <https://github.com/michalexandrov/Barter/settings>
2. Прокрутите страницу вниз до красного блока **Danger Zone**.
3. Нажмите **Change repository visibility** → **Change to public** → подтвердите.

> Секретного в репозитории нет — только файлы дашборда и библиотеки. Но ссылка станет
> общедоступной: любой, кто её знает, увидит дашборд. Если это не подходит —
> используйте раздел 4 (Netlify или Cloudflare): там сайт публикуется по ссылке,
> а репозиторий остаётся приватным.

#### Шаг 2. Включить GitHub Pages

1. Откройте <https://github.com/michalexandrov/Barter/settings/pages>
2. **Source:** `Deploy from a branch`.
3. **Branch:** `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты обновите страницу — появится адрес:
   **<https://michalexandrov.github.io/Barter/>**

#### Шаг 3. Отправьте ссылку заказчику

Он открывает её на телефоне или компьютере и работает с дашбордом самостоятельно.
Регистрация, ваш компьютер и ваш Wi-Fi не нужны. На телефоне страница
перестраивается автоматически, а свои параметры заказчик видит сразу.

> Чтобы дашборд не находили поисковики, положите в корень репозитория файл `robots.txt`
> с двумя строками: `User-agent: *` и `Disallow: /`.

#### Как обновлять дашборд потом

Правки в файлах → в VS Code на панели **Source Control** введите описание изменения,
нажмите **Commit**, затем **Sync Changes**. Либо из терминала:

```powershell
cd d:\Barter
git add -A
git commit -m "Что изменил"
git push
```

GitHub Pages обновится сам за 1–2 минуты.

### 4. Другие способы выложить в интернет

Если git использовать не хочется — загрузите готовую папку:

```powershell
cd d:\Barter
powershell -ExecutionPolicy Bypass -File .\build-dist.ps1
```

Скрипт соберёт папку `dist` и архив `dist.zip` (только файлы сайта, без заметок).

| Сервис | Что делать |
|---|---|
| **Netlify Drop** | <https://app.netlify.com/drop> → перетащить `dist.zip` в область «Drop here» → затем войти в аккаунт и нажать *Claim your project*, иначе ссылка временная |
| **Cloudflare Pages** | Create project → **Direct Upload** → перетащить папку `dist` |
| **surge.sh** (нужен Node.js) | `npm i -g surge` → `cd d:\Barter\dist` → `surge` |

Проверить собранную версию локально: <http://localhost:8000/dist/>

### 5. Бумага или PDF

Кнопка **Печать** в шапке → «Сохранить как PDF».
В печатную версию попадают показатели, выводы и графики; блок ввода скрывается.

## Автономная работа (без интернета)

Библиотеки лежат локально в папке `vendor/`, поэтому дашборд работает **без подключения
к сети** — можно показывать в переговорной, где нет Wi-Fi:

```
vendor/tailwind.js       — вёрстка
vendor/chart.umd.min.js  — графики
vendor/qrcode.js         — QR-код для телефона
```

Если файлы из `vendor/` недоступны, страница автоматически подгрузит те же библиотеки
с CDN. Шрифт Inter подгружается из интернета, но при его отсутствии используется
системный — на читаемость это не влияет.

> При переносе проекта на другой компьютер копируйте папку целиком
> (`index.html`, `app.js`, `styles.css`, `vendor/`), иначе часть оформления потеряется.

## Что показать в первую очередь

Дашборд состоит из трёх экранов — переключаются вкладками вверху («Показатели», «Исходные данные», «Факт»).

**Экран «Показатели»** (то, что интересно заказчику):

- **4 главные цифры** — чистая прибыль, ROI, эффективная цена ваты, отклонение от прайса.
- **Два поля сделки** — объём ваты в м³ и метры квартир к зачёту. Меняете любое — второе
  пересчитывается само, баланс взаимозачёта всегда равен нулю.
- **Водопад «От суммы сделки к чистой прибыли»** — куда уходит выручка; суммы подписаны
  на каждом столбце: скидка застройщика, издержки продажи, НДС, заморозка, себестоимость, КПН.
- **Бегунок «Срок продажи»** под диаграммой — сразу видно, как задержка продажи съедает прибыль.

**Экран «Исходные данные»** — ставки и цены (НДС, КПН, доходность альтернативы; завод:
прайс и себестоимость 1 м³; застройщик: цена 1 м² и скидка по договору; продажа: скидка
быстрой продажи, комиссия риелтора, прочие расходы). Здесь же кнопки-пресеты — сразу
показать осторожный и оптимистичный сценарий.

**Экран «Факт»** — журнал операций «план / факт / отклонение»: впишите фактические суммы
(или нажмите «Скопировать план») и сравните факт с планом.

Цветовая логика интерфейса: белые поля с синим акцентом и бейджем «ввод» — можно менять,
серые блоки с бейджем «авто» — рассчитывается само.
